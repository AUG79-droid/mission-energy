# Mission Energy · Sustainability in Service

Independent bilingual (English / Spanish) learning application covering energy security and resilience for aerospace In-Service operations.

## Learning journey

1. Supply Disruption — understand dependencies and critical loads.
2. Efficiency That Protects Missions — energy performance and demand flexibility.
3. Diversifying Supply — energy sources, storage and verified backups.
4. Infrastructure Readiness — maintenance, extreme weather and restoration.
5. The 72-Hour Challenge — fictional decision exercise under compounding constraints.

The application has 5 missions, 25 in-depth lesson sections, 50 scenario-based decisions, an interactive scoring panel and a final assessment. All scenarios are illustrative; they do not describe Airbus site equipment, approved procedures or actual resilience capabilities.

## Deployment

- Static site: `index.html`, `content.js`, `theory.js`, `patch.js`.
- No backend, installation, external image service or build pipeline is required.
- Enable GitHub Pages in **Settings → Pages → Deploy from a branch**, selecting `main` and `/(root)`.
- Once GitHub completes its deployment, the intended address is https://aug79-droid.github.io/mission-energy/
- Application progress is saved locally in the browser; using another device or clearing site data resets local progress.

This is a separate repository and does not require changing any Sustainability Navigator deployment settings.
